# Day 6 — Visual EDA with Matplotlib and Seaborn

## Overview

This project is part of my AI/ML learning roadmap.

On Day 6, I learned visual exploratory data analysis using Matplotlib and Seaborn.  
The project analyzes an employee dataset using charts, summary tables, correlation analysis, and written insights.

## Topics Covered

- Visual EDA workflow
- Matplotlib basics
- Line plot
- Bar chart
- Scatter plot
- Histogram
- Seaborn countplot
- Seaborn histplot
- Seaborn boxplot
- Seaborn scatterplot
- Correlation heatmap
- Plot debugging
- GitHub project documentation
