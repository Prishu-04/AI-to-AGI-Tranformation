# Classes, Objects, and Methods Deeper
## 1. Class vs Object
## Class
A class is a blueprint.
```Python
class Student:
    pass
```
This only defines the structure. It does not create a real student yet.
## Object
An object is created from the class.
```Python
student1 = Student()
student2 = Student()
```
Now `student1` and `student2` are two separate objects.
Think:
```
Class  = Student design
Object = Rahul, Aman, Priya
```
