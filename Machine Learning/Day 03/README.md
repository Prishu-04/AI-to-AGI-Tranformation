# Day 3 — NumPy Student Analytics

## Overview

This project is part of my AI/ML learning roadmap.  
On Day 3, I learned NumPy fundamentals and built a student analytics system using NumPy arrays.

The project analyzes student marks, attendance, and study hours, calculates basic statistics, scales features, applies weighted scoring, categorizes students, and saves an analytics report.

## Topics Covered

- NumPy arrays
- Shape, ndim, size, dtype
- Indexing and slicing
- Boolean filtering
- Vectorized operations
- Broadcasting
- Feature scaling
- Weighted scoring
- NumPy debugging
