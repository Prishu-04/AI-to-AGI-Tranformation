## 🧠 Mini Project

# Student Marks Analyzer

The mini project for Day 2 was based on analyzing student marks using Python and NumPy.

---

## 🎯 Project Objective

The objective of this project is to analyze student marks and generate a complete report using NumPy.

The program performs the following tasks:

- Stores student names and marks
- Converts marks into a NumPy array
- Calculates total marks of each student
- Calculates average marks of each student
- Assigns grades based on average marks
- Checks pass/fail status
- Finds the class topper
- Saves the final report into a text file
