# Day 4 — Pandas Employee Data Analysis

## Overview

This project is part of my AI/ML learning roadmap.  
On Day 4, I learned Pandas basics and built an employee data analysis project.

The project creates an employee DataFrame, inspects the dataset, adds employee levels, filters records, sorts salaries, calculates analytics, and exports the final report as CSV.

## Topics Covered

- Pandas Series and DataFrame
- CSV handling
- Data inspection
- Filtering rows
- Selecting columns
- Sorting data
- Adding new columns
- Debugging Pandas errors
