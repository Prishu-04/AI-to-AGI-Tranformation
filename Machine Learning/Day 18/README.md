# Loan Approval Prediction System

## Overview
An end-to-end binary classification project that predicts
loan approval eligibility using mixed numerical and
categorical application data.

## Models Compared
- Logistic Regression
- K-Nearest Neighbors
- Decision Tree
- Random Forest
- Gaussian Naive Bayes

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix
- Business Cost

## Workflow
1. Data generation and inspection
2. Train-validation-test split
3. Numerical and categorical preprocessing
4. Model comparison
5. Threshold tuning
6. Final test evaluation
7. Error analysis
8. Model persistence
9. Input validation

## Important Note
This project is educational and must not be used as the
sole decision-maker in real lending.
