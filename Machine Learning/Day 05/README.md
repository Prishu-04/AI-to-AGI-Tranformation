# Day 5 — Student Data Cleaning Project

## Overview

This project is part of my AI/ML learning roadmap.  
On Day 5, I learned data cleaning using Pandas and built a messy student dataset cleaning project.

The project handles missing values, duplicate rows, wrong data types, invalid ranges, outliers, text inconsistencies, and exports a cleaned CSV file.

## Topics Covered

- Missing value detection
- `fillna()` and `dropna()`
- Duplicate removal
- Type conversion using `pd.to_numeric()`
- Outlier handling using `clip()`
- Text standardization
- Rule-based result creation
- CSV export
